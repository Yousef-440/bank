# 🏦 Bank Landing Page
A clean and responsive **bank landing page** built using **HTML**, **CSS**, and **JavaScript**. This project serves as a front-end representation of a bank’s official website, showcasing its services, values, and customer testimonials.

## 📌 Features
- About the bank section
- Services overview (Accounts, Loans, Cards)
- Customer testimonials
- Contact section
- Simple interactivity with JavaScript (smooth scrolling, animations)

## 🛠️ Technologies Used
- **HTML5** - **CSS3** - **JavaScript**
